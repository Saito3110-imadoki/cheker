# 公式LINE メッセージ文面（マカセル）

LPの導線をすべて公式LINE（https://lin.ee/Ngu1hNN）に集約したため、
LINE公式アカウント側で設定する文面をここにまとめています。

- 設定場所：LINE Official Account Manager →「あいさつメッセージ」「応答メッセージ」
- 応答モードは **「Bot」＋（チャットも併用するなら）手動チャットON** を推奨
- 数字はLPと揃えています（ライト¥9,800／スタンダード¥19,800／プロ¥49,800・税抜、
  10日間無料トライアル、初期費用0円、最低契約期間6ヶ月）。LPを変えたらここも直す
- **営業時間は仮で「平日10:00〜19:00／土日祝休み」としています。実態に合わせて修正してください**

---

## 1. あいさつメッセージ（友だち追加時）

> 吹き出しは4つに分けて登録します（LINEの上限は5つ／1つあたり500文字）。
> 冒頭の「＜友だちの表示名＞」は、管理画面の「友だちの表示名」ボタンで挿入してください。

### 吹き出し1

```
＜友だちの表示名＞さん、友だち追加ありがとうございます！
SNS自動投稿サービス「マカセル」（株式会社IMADOKI）です。

マカセルは、ネタ探し・投稿文づくり・図解画像の作成・X / Threadsへの投稿・効果分析まで、
SNS運用をまるごと自動化するサービスです。

あなたの仕事は、1日2分の承認だけ。
```

### 吹き出し2

```
▼ ただいま実施中
10日間の無料おためし

・初期費用 0円
・クレジットカード登録不要
・合わなければ、そのまま終了でOK

このトークに「おためし希望」と送っていただければ、担当者からご案内します。
```

### 吹き出し3

```
お申し込みのときは、この3つを送っていただけるとスムーズです。

① 会社名・お名前
② 業種（例：工務店／美容室／人材紹介）
③ 運用したいSNS（X / Threads / 両方）

翌営業日までにご返信し、最短で翌日から投稿をスタートできます。
初期設定はこちらで行いますので、準備は不要です。
```

### 吹き出し4

```
気になることは、キーワードを送るだけでもOKです。

「料金」→ プランと費用
「機能」→ できること
「事例」→ 投稿・レポートの実例
「解約」→ 解約について

もちろん、そのまま質問を書いていただいても大丈夫です。
しつこい営業のご連絡はいたしませんので、お気軽にどうぞ。
```

```

① 会社名・お名前 ② 業種 ③ 運用したいSNS（X / Threads / 両方）

「おためし希望」＋ ①会社名・お名前 ②業種 ③運用したいSNS
を送っておいていただければ、翌営業日にそのまま手続きを進めます。

※このメッセージは自動送信です。

## 3. キーワード応答

| キーワード（一致条件） | 返す内容 |
| --- | --- |
| おためし / 無料 / トライアル / 申し込み / 申込 | 3-1 |
| 料金 / 価格 / 費用 / プラン / いくら | 3-2 |
| 機能 / できること / 何ができる | 3-3 |
| 事例 / 実例 / サンプル / 実績 | 3-4 |
| 解約 / やめたい / 退会 / 契約期間 | 3-5 |
| 相談 / 打ち合わせ / 面談 / zoom | 3-6 |

### 3-1. おためし

```
10日間の無料おためし、ありがとうございます！

下記の3つを送ってください。担当者が確認しだいご案内します。
① 会社名・お名前
② 業種
③ 運用したいSNS（X / Threads / 両方）

・初期費用 0円 ／ クレジットカード登録不要
・初期設定はこちらで行います（準備は不要です）
・合わなければ、期間終了でそのまま終了できます
```

### 3-2. 料金

```
料金プランは3つです（すべて税抜・全プラン10日間の無料おためしつき）。

■ ライト　月 9,800円
　投稿案 3件/日・X自動投稿・Notion承認フロー

■ スタンダード　月 19,800円（いちばん選ばれています）
　投稿案 5件/日・X / Threads自動投稿・図解画像の自動生成・効果測定＋AI自動学習

■ プロ　月 49,800円
　投稿案 10件/日・複数アカウント / 複数ブランド管理・専任サポート

初期費用は0円、最低契約期間は6ヶ月です。
どのプランが合うか分からない場合は、業種とSNSの現状を教えてください。おすすめをご提案します。

詳しくは → https://social-post-pilot.com/#pricing
```

### 3-3. 機能

```
マカセルがやることは、SNS運用のほぼ全部です。

1. ネタ探し（業界ニュース・自社の切り口から自動で企画）
2. 投稿文の作成（アカウントの文体を学習）
3. 図解画像の自動生成（会社名・ブランドカラー入り）
4. X / Threadsへの自動投稿（時間帯も最適化）
5. 効果測定と週次レポート（次にやることまで提案）

あなたがやるのは、Notionに届いた投稿案を「承認」するだけ。1日2分で終わります。
※ 承認もスキップして完全自動にする設定も選べます。

詳しくは → https://social-post-pilot.com/#solution
```

### 3-4. 事例

```
実際の投稿・図解画像・週次レポートのサンプルはLPで公開しています。

・AIが自動生成した投稿と図解画像 → https://social-post-pilot.com/#proof
・毎週届く効果レポート → https://social-post-pilot.com/#report

「自分の業種だとどんな投稿になるか見たい」というご要望も多いので、
業種を教えていただければ、サンプルの投稿案をお作りしてお送りします。
```

### 3-5. 解約

```
契約についてのご案内です。

・最低契約期間は6ヶ月です（10日間の無料おためし期間は含みません）
・無料おためし期間中は、費用は一切かかりません。合わなければそのまま終了でOKです
・期間終了後の解約も、このLINEにご連絡いただければ手続きします

ご不明な点があれば、遠慮なくお送りください。
```

オンライン（Zoom / Google Meet・30分程度）での打ち合わせも承っています。

① 会社名・お名前

を送ってください。折り返し調整いたします。
```
