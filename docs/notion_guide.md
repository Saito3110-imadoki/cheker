# Notion データベース設定ガイド

AIが生成した投稿案を管理するNotionデータベースの詳細な設定方法です。

---

## データベース構成

### 必須プロパティ一覧

| プロパティ名 | 種類 | 説明 |
|---|---|---|
| 投稿文 | タイトル | AIが生成した投稿テキスト（X向け） |
| Threads用文面 | テキスト | Threads向けに書き分けた文面（未作成でも動作、その場合はX文面を使用） |
| リプライ文面 | テキスト | X投稿直後に自動でぶら下げるセルフリプライ（未作成でも動作、その場合はリプライなし） |
| 投稿日時 | 日時 | 投稿候補の日時（自動設定） |
| 媒体 | マルチセレクト | 投稿するSNS |
| ステータス | マルチセレクト | 承認フロー管理 |
| 画像URL | URL | 図解画像へのリンク |

### パフォーマンス計測プロパティ（任意・毎日自動更新）

| プロパティ名 | 種類 | 説明 |
|---|---|---|
| X投稿ID | テキスト | 自動投稿後に記録されるツイートID |
| いいね数 | 数値 | Xのいいね数（毎日22時に自動更新） |
| RT数 | 数値 | リツイート数 |
| リプライ数 | 数値 | リプライ数 |
| インプレッション | 数値 | 表示回数 |
| 計測日時 | 日時 | 最終計測日時 |

> **注意**: パフォーマンス計測を使うには、Notionデータベースに上記6つのプロパティを追加してください。追加しなくても他の機能は正常に動作します。

---

## ステータスの使い方

| ステータス | 意味 | 操作 |
|---|---|---|
| **承認待ち** | AIが生成、未確認 | 毎朝自動セット |
| **未投稿** | 承認済み、投稿待ち | あなたが手動で変更 |
| **投稿済み** | 投稿完了 | 投稿後に変更 |
| **却下** | 不採用 | 使わない投稿に設定 |

### 毎日の承認フロー
1. 朝7時にLINEで通知が届く
2. Notionを開き「承認待ち」の投稿を確認
3. 良い投稿 → ステータスを「未投稿」に変更
4. 不要な投稿 → ステータスを「却下」に変更

## おすすめのビュー設定

### ビュー①｜今日の承認タスク（フィルタービュー）

1. 「+ビューを追加」→「テーブル」を選択
2. 名前：「📋 今日の確認」
3. フィルター：ステータス = 「承認待ち」

### ビュー②｜今週の投稿カレンダー

1. 「+ビューを追加」→「カレンダー」を選択
2. 名前：「📅 投稿カレンダー」
3. 表示プロパティ：投稿日時
4. フィルター：ステータス = 「未投稿」

### ビュー③｜画像付き投稿一覧

1. 「+ビューを追加」→「ギャラリー」を選択
2. 名前：「🖼 図解付き投稿」
3. カードプレビュー：画像URL
4. フィルター：画像URL = 空でない

## プロパティ名を変更したい場合

Notionのプロパティ名を変えた場合、`config.yaml` の `notion.properties` セクションも合わせて変更してください。

**例：「投稿文」を「本文」に変更した場合**

```yaml
notion:
  properties:
    text: 本文       ← ここを変更
    datetime: 投稿日時
    platform: 媒体
    status: ステータス
    image_url: 画像URL
```

## Notionのインテグレーション権限確認

インテグレーションが正しく接続されているか確認する方法：

1. データベースページを開く
2. 右上「・・・」→「コネクト」をクリック
3. 設定したインテグレーション名にチェックが入っていればOK

---

## データベースIDの確認方法

URLから確認する場合：
```
https://www.notion.so/myworkspace/abc123def456ghi789jkl012mno345pq?v=...
                                  ↑ここが32文字のデータベースID
```

ハイフン区切りの場合はハイフンを除いた32文字を使用してください。
